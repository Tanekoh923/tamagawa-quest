# たまがわクエスト

大田区立多摩川小学校をテーマにした、小学生向けの非公式クイズゲーム。

## 遊び方

**`たまがわクエスト.html` をブラウザで開くと遊べます。** この1ファイルだけで動くので、別のパソコンにコピーしても遊べます。インストール不要で、ネットにつながっていなくてもゲーム本体は動作します（公式の出典リンクを開くときはネット接続が必要です）。分割された編集用ファイルは `index.html` です。

Node.js がある場合は、このフォルダで `node server.cjs` を実行し、http://127.0.0.1:4173 を開いても遊べます。

- 「冒険に出発！」：全100問から重複なしで10問をランダム出題。選択肢もランダム。
- 5つのテーマ：各テーマの問題からランダムに10問の練習。通常の冒険の最高記録とは分けます。
- 答えたあと：正解と解説を表示。「次の問題へ」で進みます。
- 結果：得点、全回答の振り返り、間違えた問題だけの復習、新しい10問。
- 発見図鑑：全100問の正解と解説をテーマ別に確認。
- ふりがな：表示を切り替え可能。読み上げ：対応するブラウザ・日本語音声で利用可能。
- 音：初期設定はOFF。ONにすると回答時の短い効果音が鳴ります。
- 操作：タップ／クリック、TabとEnter、回答は1・2・3キーにも対応。

時間制限はありません。名前の入力、ランキングへの送信、外部フォントやライブラリへの通信はありません。記録は端末のブラウザ内のみ保存します。保存機能を使えない環境でもゲームは動きます。ふりがなは主要な漢字語に対応しています。画面幅に合わせてスマートフォン・タブレット・パソコンで表示が変わります。

2026年10月5日に公式サイトを確認しました。`questions.js` に問題データと出典リンクがあります。学校の事実を扱う問題60問と、教育目標をもとにしたオリジナルの生活問題40問、合計100問です。毎年変わる児童数や教職員名は出題していません。

学校や教育委員会が制作・監修したゲームではありません。公式キャラクター画像・写真は使用していません。画面の学校風景はオリジナルのイメージイラストで、実際の校舎の形を再現したものではありません。

## 編集

問題の追加・変更は `questions.js`、画面や動作は `app.js`、デザインは `style.css` を編集します。各問題には正解1個・誤答2個・解説・出典があります。

変更後に `node build.cjs` を実行すると、持ち運び用の `たまがわクエスト.html` が更新されます。
