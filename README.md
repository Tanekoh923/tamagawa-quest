# たまがわクエスト

大田区立多摩川小学校をテーマにした、小学生向けの非公式クイズゲーム。

## すぐ遊ぶ

**[たまがわクエストを遊ぶ（公開ページ）](https://tanekoh923.github.io/tamagawa-quest/)**

スマートフォン・タブレット・パソコンのブラウザで、インストール不要で遊べます。通常100問＋ハード30問を収録しています。

### 単独HTML版で遊ぶ（オフライン・持ち運び用）

1. [`たまがわクエスト.html` をダウンロード](https://github.com/Tanekoh923/tamagawa-quest/raw/refs/heads/main/%E3%81%9F%E3%81%BE%E3%81%8C%E3%82%8F%E3%82%AF%E3%82%A8%E3%82%B9%E3%83%88.html)。
2. 保存したファイルをブラウザで開きます。

この1ファイルだけで動くので、別のパソコンにコピーしても遊べます。ゲーム本体はネット接続不要です（公式の出典リンクを開くときはネット接続が必要です）。

## 遊び方

- 「冒険に出発！」：全100問から重複なしで10問をランダム出題。選択肢もランダム。
- 「ハードに挑戦」：専用の難問30問から重複なしで10問をランダム出題。4択で、順番・計算・組み合わせ・地域活動の判断を問います。最高記録と冒険回数は通常とは別に保存します。
- 5つのテーマ：各テーマの問題からランダムに10問の練習。通常の冒険の最高記録とは分けます。
- 答えたあと：正解と解説を表示。「次の問題へ」で進みます。
- 結果：得点、全回答の振り返り、間違えた問題だけの復習、新しい10問。
- 発見図鑑：通常100問とハード30問を切り替え、正解・解説をテーマ別に確認。
- ふりがな：表示を切り替え可能。読み上げ：対応するブラウザ・日本語音声で利用可能。
- 音：初期設定はOFF。ONにすると回答時の短い効果音が鳴ります。
- 操作：タップ／クリック、TabとEnter、回答は1・2・3キー（ハードは4も）に対応。

時間制限はありません。名前の入力、ランキングへの送信、外部フォントやライブラリへの通信はありません。記録は端末のブラウザ内のみ保存します。保存機能を使えない環境でもゲームは動きます。ふりがなは主要な漢字語に対応しています。画面幅に合わせてスマートフォン・タブレット・パソコンで表示が変わります。

## 編集

分割された編集用ファイルの入口は `index.html` です。ローカルで確認する場合は、Node.js がある環境でこのフォルダの `node server.cjs` を実行し、http://127.0.0.1:4173 を開きます。

問題の追加・変更は `questions.js`、画面や動作は `app.js`、デザインは `style.css` を編集します。通常問題は `QUESTIONS`（正解1個・誤答2個）、ハード問題は `HARD_QUESTIONS`（正解1個・誤答3個）です。各問題に解説・出典があります。通常のID 1〜100を保持し、ハードには101〜130を使用します。記録は既存の保存キーのまま引き継ぎます。

変更後に `node build.cjs` を実行すると、持ち運び用の `たまがわクエスト.html` が更新されます。

動作確認：`node verify-hard.cjs` で、通常100問の保持・難問30問の構成・抽選・記録の引き継ぎ・モード別の最高記録・復習と再挑戦を確認できます。
